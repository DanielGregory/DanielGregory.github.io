R Projects

  • Rocket Launch Success Rate Analysis – Code Repository
    View Full Report (PDF)

    Analyzing Post-First Launch Success Rates
    This project investigates the success rates of space launch vehicles after their first launch, providing insight into reliability trends across various rocket families.

    Key Objectives:
    - Determine how likely a rocket is to succeed after its initial launch attempt.
    - Identify patterns in success rates over time and across different vehicles.
    Methods & Insights:
    - Created visualizations including density plots and cumulative success rate charts.
    - Found that many rockets show a steep increase in success rate after their second or third launch.
    - Highlighted outliers where reliability remained low or decreased due to design changes or operational challenges.

    Conclusion:
    Rockets typically become significantly more reliable after their first few launches. This trend supports iterative design and testing strategies used by modern launch providers.

AWS Projects

Tools/Technologies: AWS IoT Core, AWS Greengrass, AWS Lambda, EC2, MQTT, CI/CD Pipeline

Built a cloud-based IoT data ingestion and processing pipeline using AWS as part of an emissions analysis lab project. Simulated vehicle emission data (specifically CO₂ levels) was published via MQTT, routed through Greengrass for local edge processing, and processed by AWS Lambda functions to calculate maximum CO₂ levels for each vehicle. This setup was used to help diagnose engine issues by analyzing real-time emission data, mimicking how emission analyzers are used in automotive diagnostics.

  • Configured AWS IoT Core for secure MQTT message routing.
  • Set up AWS Greengrass for edge device simulation and local compute.
  • Deployed AWS Lambda functions for serverless data handling.
  • Provisioned and managed EC2 instances to support the pipeline and simulation.
  • Integrated a CI/CD pipeline for automated deployment of components.
  • Simulated real-time data with an MQTT publisher to test end-to-end flow.

MATLAB Projects

  • Numerical Method for Singularly Perturbed Convection-Diffusion Problems

This project contains the MATLAB code used in my research on developing a numerical method to solve singularly perturbed convection-diffusion problems. The method addresses the challenges in solving these types of partial differential equations, where standard approaches often fail due to the presence of small perturbations.

The code implements techniques for efficient approximation, focusing on accuracy and stability in the presence of such perturbations. This project highlights my ability to apply mathematical modeling and numerical analysis to solve complex scientific problems.

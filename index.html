Machine Learning Projects

AI-Driven Swing Trading Models

Category: Machine Learning / Finance

Description: Developed machine learning models to predict 1-day stock price movements across the S&P 500, with performance optimizations and accuracy-based signal adjustments to increase profitability.

  • Key Features:
    • SGDClassifier model for directional market predictions.
    • Recurrent Neural Network (RNN) optimized for profit over accuracy.
    • Reinforcement Learning (RL) agent that adapts to changing market conditions.
    • Prediction-flipping logic for sub-50% accuracy stocks to reverse signals.
  • Results:
    • SGD Model: 55–56% accuracy; $200 average profit per $5k daily investment over 50 days for high-accuracy stocks.
    • RNN Model: ~54% accuracy; $630 average profit per $5k daily investment over 50 days for high-accuracy stocks.
    • RL Model: Early testing shows consistent positive returns with adaptive strategies.
  • Tools & Tech: Python, scikit-learn, TensorFlow/Keras, Reinforcement Learning frameworks, Google Colab.

01

AI Swing Trading Models

Equity curve vs. benchmark
SGD vs RNN vs RL comparison

Problem

Identifying consistent alpha on 1-week equity moves without overfitting to historical data or relying on hand-coded swing rules.

Approach

Trained three models in parallel: SGDClassifier as baseline, an RNN to capture sequential price dynamics, and a reinforcement learning agent for policy-based decisions. The RNN outperformed and became the production model running weekly on live data.

Stack

  • Python
  • scikit-learn
  • TensorFlow
  • pandas
  • NumPy
  • S&P 500 data

Result

~15% portfolio return since June. The model runs weekly on live data and directly led to my current role in applied finance.
